# LG Aimers 9기 해커톤

야구 투구 제구 성공 확률을 예측하는 머신러닝 해커톤에 참여했습니다. 온라인 해커톤(Phase 2)에서 모델링과 실험 검증을 수행했고, 그 경험을 바탕으로 오프라인 해커톤(Phase 3) 본선에 진출해 **최종 20위**를 기록했습니다.

> 이 저장소는 개인 포트폴리오용 기록입니다. 대회 규정을 준수하기 위해 원본 데이터, 제출 파일, 학습된 모델 가중치 및 재현 가능한 추론 코드는 포함하지 않습니다.

## 성과

| 구분 | 내용 |
| --- | --- |
| Phase 2 | 온라인 해커톤 참여 · 데이터 분석, 피처 설계, 모델 실험 및 검증 수행 |
| Phase 3 | 오프라인 해커톤(본선) 진출 |
| Final Ranking | **20위** |

## 문제 정의

투구 상황과 선수 관련 정보를 바탕으로 투구 제구 결과의 확률을 예측하는 분류 문제를 다뤘습니다. 단순히 전체 정확도를 높이는 데 그치지 않고, 투수별 예측 품질까지 함께 고려해야 하는 평가 구조에 맞춰 실험을 설계했습니다.

## Phase 2 — 온라인 해커톤

### 수행 내용

- 데이터의 시즌·선수·경기 상황 단위 분포를 탐색하고, 결측값과 범주형 변수의 처리 기준을 정리했습니다.
- 투수의 과거 기록, 투구 카운트, 이닝·주자 상황 등 문제 맥락을 반영한 피처를 설계했습니다.
- 여러 분류 모델을 비교하고, 확률 예측 품질을 기준으로 개선 방향을 검증했습니다.
- 시간 순서를 보존한 검증 세트를 구성해 미래 정보가 학습에 섞이지 않도록 관리했습니다.
- 단일 모델의 편향을 줄이기 위해 후보 모델의 예측 특성과 오차 패턴을 비교했습니다.

### 배운 점

리더보드 점수만으로 모델을 선택하면 특정 기간에만 맞는 규칙을 채택할 위험이 있었습니다. 그래서 데이터 분할 기준, 피처 생성 시점, 확률 보정 방식을 함께 기록하며 재현 가능한 실험 흐름을 만드는 데 집중했습니다.

## Phase 3 — 오프라인 해커톤 본선

Phase 2의 경험을 바탕으로 본선에 진출했습니다. 본선에서는 제공된 공식 데이터만 활용하고, 각 평가 행을 독립적으로 예측해야 하는 규칙 안에서 모델을 개선했습니다.

### 수행 내용

- 시계열 기준의 학습·검증 분할을 고정하고, 실험별 설정과 결과를 문서화했습니다.
- 확률의 합, 출력 순서, 단일 행·셔플·부분 입력에서도 결과가 일관적인지 점검했습니다.
- 후보 모델의 성능뿐 아니라 투수 단위 순위 품질과 기간별 안정성을 함께 비교했습니다.
- 팀 실험 결과를 공유할 수 있도록 재현 절차, 설정, 검증 결과를 구조화했습니다.

### 결과

**Phase 3 본선 진출 · 최종 20위**
